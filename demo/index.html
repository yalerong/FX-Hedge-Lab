FX Hedge Lab · 演示

把汇率预测关进闸门里的
企业套保决策台

这个工作台的决策变量是套保比例，不是汇率方向。预测不会告诉你"该不该锁"， 它只被允许做一件事：在四道闸门全过之后，把已定的目标比例往下打一个折扣。 只降不升——预测对你不利时，一律足额锁。

Python 标准库 · 无数据库 75 条测试 合成数据 两轮样本外 · 均登记负结果

02 · 决策台

套保比例不是赌方向，是收窄损益带宽

拖动目标套保比例，看四个情景下的合计损益。比例越高，乐观与悲观两端的差距越小—— 这就是套保买到的东西：不是更高的期望，是更窄的分布。

80%
情景USD 合计EUR 合计两币种合计（CNY）

情景 = 当前汇率 ±3%（乐观 / 悲观）与 +1%（自定义）。合计损益 = 敞口浮动损益 + 套保损益， 即"剩余未锁部分 × 汇率变动"。

把比例拉到 100%：四个情景的合计损益全部归零，带宽消失。 拉到 42% 以下时建议新增锁汇为 0——已经执行的 50 万美元远期已经覆盖了这个比例， 系统不会为了凑比例去反向平仓。

03 · 压轴

预测折扣闸门：四道闸门，全部只降不升

Prophet 月度预测 + 滚动回测给出一个信号（档位 / 方向 / 幅度 / 误差）。 这个信号永远不能提高套保比例，最多把它打到 50%。下面四个控件是信号的全部输入， 改任意一个，实时看判定与被触发的闸门。

    默认状态就是最值得看的那一格。

    样例信号：档位 support（回测质量达标）、方向上行（对收美元的出口商有利）、 预测幅度 1.4%、模型自身 MAPE 1.8%。 三个条件里两个都指向"可以少锁一点"，但信噪比闸门直接否掉： 预测的变动幅度还没跑赢模型自己的平均误差，这个方向判断在噪声里，不足以支撑降低套保。 把幅度拖过 1.8%，折扣才会出现。

    四道闸门原文

    • 1回测区间覆盖率：可回测区间覆盖名义区间 <80% 降一档，<40% 直接 reject。
    • 2样本量与显著性：support 档要求 n≥24 且方向准确率的单侧二项检验 p≤0.10，否则降档。
    • 3趋势一致性（GMMA）：六层 EMA 配对 + ATR 归一化算势能，预测方向与强趋势 5/6 相反则降一档。
    • 4信噪比：预测幅度 ≤ MAPE 时，即使方向有利也不给折扣。

    四道全部是单向的：任何一道触发只会让套保比例更高或不变，没有一条路径能让模型说服你少锁。 页面上的判定逻辑与 web_app.py:forecast_multiplier 逐格对拍一致（96 组组合全等）。

    04 · 研究线

    两轮样本外，两次负结果，一次被硬约束挡下的"假发现"

    第二条线试图用新闻事件预测 USD/CNY 日内方向。规则在跑结果之前 commit 冻结， git 时间戳是"没有先看行情再挑新闻"的唯一凭证。两轮样本外各只跑一次，跑完即定论。

    轮次样本外 n命中率p 值安慰剂增量检验结论
    v1 · 新闻事件方向20753.14% 0.202219.9%p=0.50 五条过两条
    v1 · 波动目标—比值 0.929 0.478—— 三条全不过
    v2 · 境内变量 + 新闻筛选11054.55% 0.195518.2%p=0.5094 不通过
    v2 · 基线（去掉新闻）11054.70% ——— 比加新闻更高

    结论写进仓库：新闻相对于已经能看到的市场变量没有可验证的增量信息。 未过验收的信号不接入上面那个折扣器——原计划的接入 PR 直接取消。

    最值得讲的一格：一个 78.6% 的假发现是怎么被挡住的。

    同一批数据里有一个漂亮得多的数字：r0（事件当日收益）样本外命中 61.24%， 严格档 78.57%，p = 0.0001。 但它不可交易——r0 与规则的输入变量处于同一时段， "用当天的市场反应去预测当天的市场反应"是同义反复。 预注册里那条"意外与响应必须分段测量"的硬约束，单独挡掉了这一个假发现。 同样地，v2 里 rF 三条预注册条件字面上全过，仍被否决： 零假设选错（该比的是"永远看多"而不是 50%）+ 中间价是参考价不可成交。

    05 · 边界

    • ·本页所有敞口、锁汇、汇率均为合成演示数据，不含任何真实企业的头寸或对手方。
    • ·本页是纯静态复刻。真实工具在本地运行（Python 标准库 HTTP 服务 + JSON 文件），没有下单通道，不连银行、不发指令。
    • ·预测模块是可选的：信号文件缺失或档位不达标时，系统按目标比例足额锁汇，行为与没有模型时完全一致。
    • ·回测回答的是"按已记录的锁汇执行，到期相对实际汇率贡献了多少人民币"，不是预测。
